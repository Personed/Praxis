# apps/site

Static Modus site (HTML/CSS, no build step or dependencies).
Deploy with Root Directory = `apps/site`; `vercel.json` supplies clean URLs and security headers.

English pages: `/`, `/download`, `/privacy`, `/terms`. Portuguese copies live under `/pt-br/`.
Privacy and terms remain drafts awaiting approval. The app uses local models or user-configured
external providers, with no Modus account, subscription or credit checkout.
